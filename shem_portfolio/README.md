# Shem Okebiro — Portfolio (Django + Vintage Coffee Theme)

A single-page personal portfolio built with Django. Everything on the page
(name, tagline, background photo, social links, projects) is managed from
the Django admin — no code edits needed to update content.

## Visual direction

- **Palette:** deep espresso browns, burnt rust / terracotta accents, faded cream text.
- **Typography:** `IBM Plex Mono` (navbar, labels, social/contact text) and `Anton` (large stacked headlines).
- **Navbar:** centered pill-shaped capsule with brand + expand icon, revealing an index / links / studio panel.
- **Hero:** uploaded profile picture as the full-bleed homepage background with a rusty-coffee overlay so text stays legible.
- **Icons:** Font Awesome 6 (GitHub, LinkedIn, X, Instagram, Dribbble, Behance, email, website, other).
